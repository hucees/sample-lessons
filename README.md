# Open House Sample Curriculum

A small Next.js K-4 curriculum provider website built specifically for testing external curriculum repository discovery in Open House / Homeschool Tracker.

## What is included

- Kindergarten through 4th Grade
- 4 subjects per grade:
  - Mathematics
  - Language Arts
  - Science
  - Social Studies
- 20 individual course pages
- 36 instructional weeks per course
- 36 distinct provider-hosted weekly lesson URLs per course
- 720 provider-hosted weekly lesson pages across the K–4 catalog
- 9 units per course, 4 weeks each
- Clear semantic H1/H2/H3 headings
- Stable internal links between catalog, grade, and course pages
- JSON-LD `Course` metadata on each course page
- A machine-readable `/curriculum.json` endpoint
- A `/sitemap.xml` generated by Next.js

The instructional paragraphs are intentionally dummy text. The catalog/course metadata and headings are meaningful so parsing behavior can be tested realistically.

## Run locally

```bash
npm install
npm run dev
```

Then open:

- http://localhost:3000
- http://localhost:3000/catalog
- http://localhost:3000/curriculum.json

## Deploy to Vercel

1. Extract this folder.
2. Create a new GitHub repository and push the project, or import the folder into your preferred deployment workflow.
3. Create a new Vercel project from the repository.
4. Deploy using the defaults.
5. Optional: set `NEXT_PUBLIC_SITE_URL` to your final public HTTPS origin so `sitemap.xml` uses the deployed URL.

No database, API keys, or environment variables are required for the site itself.

## Suggested Open House tests

Try feeding Open House each of these public URLs after deployment:

1. `/` — general provider home page
2. `/catalog` — HTML page containing all 20 course cards
3. `/grades/grade-4` — one-grade catalog page
4. `/grades/grade-4/mathematics` — individual provider-hosted course with 36 weekly lesson links
5. `/grades/grade-4/mathematics/week-1` — distinct provider-hosted weekly lesson
6. `/curriculum.json` — machine-readable complete catalog including lesson URLs

This gives you several different real-world ingestion surfaces without changing the underlying curriculum data.
